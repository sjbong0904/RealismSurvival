# 에이전트 프롬프트 — 퀘스트 진행·카테고리 전면 재설계

> **역사 기록 (패치 6.6)**: 재설계 당시의 작업 프롬프트다. 현재 퀘스트 정본은 `tools/quest_v1/` 생성기와 `pack/config/ftbquests/quests`이며, 이 문서의 수치·구성은 현행이 아니다.

아래 **복사용 프롬프트**를 새 에이전트 채팅에 붙여 넣으면 된다.  
모드 설명은 `docs/MOD_CATALOG.md`, 보상·시간·튜토리얼 상세는 `docs/MODPACK.md`를 함께 넘긴다.

---

## 복사용 프롬프트

```text
# 역할
당신은 마인크래프트 모드팩 **Realism Survival**(NeoForge, 마인크래프트 26.1.2)의
**FTB Quests(퀘스트 책) 진행 구조·카테고리 디자이너**다.

목표는 퀘스트 책의 **큰 탭(그룹), 장(챕터), 열리는 순서, 플레이 루프를 전면 재설계**하는 것이다.
아이디어와 설계안이 먼저다. 퀘스트 데이터 파일을 대량으로 쓰기 전에 **설계 문서**를 낸다.

# 먼저 읽을 것 (이 저장소 기준, 순서대로)
1. `docs/MOD_CATALOG.md` — 팩에 들어간 모드와 역할. 여기에 있는 모드만 진행에 쓴다.
2. `docs/MODPACK.md` — 팩이 추구하는 방향, 시간 목표, 생존 튜토리얼 상세, 제출·보상 눈금.
3. `pack/config/ftbquests/README.md` — 퀘스트 파일 형식(JSON5), 번역(lang), 생성기 규칙.
4. 지금 구현된 책: `pack/config/ftbquests/quests/` (장 파일 + `lang/ko_kr`).
5. 상점을 진행에 넣을 때만: `docs/SHOP_SUPPLY_POST.md`.

퀘스트 내용의 기준 위치는 `pack/config/ftbquests/`다. Realism Survival 모드 jar 안에 넣지 않는다.
반영할 때는 `python tools/generate_ftbquests.py`를 존중한다.

# 이 팩이 추구하는 것
현실에 가까운 생존(갈증, 체온, 물 품질과 증류) + 요리와 계절 + 넓은 바이옴·구조물 탐험
+ 목축·펫 + 관과 탱크로 하는 가벼운 자동화.

엔딩: 생존·음식·탐험·목축·공방 다섯 분야에서 실력을 모은 뒤(번들·인장 등),
도감을 채우고 **완벽(Perfection)** 에 도달한다.

초반 경험의 참고: 다른 팩 Society: Sunlit Valley처럼,
처음에는 튜토리얼(과 필요한 팁)만 펼쳐 보이고, 번들과 도감은 나중에 연다.

월드의 물은 전부 **등급이 있는 물**이다. 증류·필터·안전한 물이 초반 핵심이다.
백팩은 가방 칸을 늘리는 용도다. 워프스톤은 사람마다 거점을 소수만 둔다.
벌목은 Treeliable로 나무 크기만큼 손이 가게 한다.
멀티에서 파티·땅·지도는 FTB Teams + FTB Chunks로 다루고, 제출·마시기는 각자 한다.
보상은 “지금 막 가능해진 것”이나 “바로 다음에 쓸 재료” 수준이다
(`docs/MODPACK.md`의 「제출·보상 눈금」).

챕터·퀘스트 제목과 설명 초안은 **한국어**로 쓴다. 영문은 같이 적어도 된다.

# 지금 책 구조 (참고 — 버려도·섞어도 됨)
큰 탭: 튜토리얼 / 가이드 / 번들 / 도감
흐름: 시작하기 → 생존 → 밭과 부엌 → 밖으로 → 깊은 곳 → 자동화 → 생존 팁 →
번들 다섯 방 → 도감(+완벽)

문서상 목표 개수: 시작하기 열 개 안팎, 튜토리얼 이백오십 전후, 가이드 백 전후,
번들 서른 전후, 도감 칠백 이상 → 합쳐 천 개 안팎.
실제로 만들어진 양은 튜토리얼 각 장이 삼십~사십오, 가이드는 적고,
번들 방마다 이십 전후, 도감은 음식·바이옴이 두껍고 완벽은 아직 얇다.

중요한 것은 개수를 흉내 내는 일이 아니라,
**탭 경계, 처음 안내, 열리는 순서, 모드를 처음 만나는 타이밍**이 플레이어에게 분명한가이다.

# 플레이어가 본편에서 만나야 하는 경험
(어느 탭·어느 장에 둘지는 재배치해도 된다. 설명집에 있는 콘텐츠 모드를 의미 있게 녹인다.)

- Realism Survival: 물 등급, 갈증, 체온, 필터와 증류, 온도계 같은 계측
- Serene Seasons, SeasonHUD, Farmer's Delight, Spice of Life: Carrot Edition,
  Aquaculture, Fish of Thieves
- Biomes O' Plenty, Nature's Compass, Towns and Towers, Lootr,
  Waystones(펫 동행 포함), FTB Chunks
- Artifacts(중·후반), Treeliable(초반 안내)
- Iron Chests, Pipez, Large Fluid Tank, Sophisticated Backpacks(저장 칸)
- 선택 갈래로 두어도 됨: Q Shop, Easy NPC, SG Economy, rs-medicine

지도·레시피 찾기·성능·음성처럼 **순수 편의 모드**는 진행을 열거나 잠그는 조건으로 쓰지 않는다.
필요하면 가이드의 “읽어 보기” 팁 정도만 쓴다.

# 재설계에서 결정할 것
1. 큰 탭(챕터 그룹)을 처음부터 다시 정의한다.
   지금처럼 네 탭이어도, 이름을 바꿔도, 개수를 바꿔도 된다.
   다만 처음 켰을 때 “지금은 이것만 보면 된다 / 저것은 나중에”가 분명해야 한다.
2. 본편(스토리 클리어)은 대략 **60시간**, 도감·완벽은 **그 위에 수십 시간** 톤을 유지하거나,
   바꾸려면 이유를 적는다.
3. 무엇이 열려야 다음이 보이는지(강한 잠금 vs 추천 순서만)를 구분한다.
4. 다섯 분야(생존·음식·탐험·목축·공방) 번들·인장을 유지할지, 합치거나 이름을 바꿀지 정하고 근거를 남긴다.
5. 도감은 엔딩의 엔진이다. 장 나누기(작물, 음식, 물고기, 바이옴, 생물, 광물, 유물 등)를 다시 본다.
6. 가이드는 본편을 막지 않는다. 보상 없는 읽기와 소보상 팁의 정책을 정한다.
7. 상점·의학은 선택 갈래로 둘지, 본편 한쪽에 넣을지 정한다.
8. 여럿이 할 때(파티·개인 상자·각자 제출)를 전제로 한 문장을 설계에 넣는다.

# 낼 결과물 (이 순서)
## A. 한 페이지 비전
- 처음부터 엔딩까지 플레이어가 느끼는 이야기 한 단락
- 탭 구조를 글자로 그린 나무
- 본편 / 수집 / 선택 갈래의 시간 예산

## B. 카테고리(큰 탭) 표
| 가칭 아이디 | 화면에 보일 이름 | 처음에 펼쳐 보이나 | 역할 | 예상 퀘스트 수 | 열리는 조건 |

## C. 장(챕터) 표
| 가칭 아이디 | 속한 탭 | 목표 | 핵심 모드 | 클리어(왕관) 조건 | 앞선 의존 | 예상 개수 |

## D. 진행 그림
- 반드시 밟는 길
- 옆으로 빠져도 되는 길(가이드, 상점, 의학, 유물 등)
- 완벽(Perfection)에 들어가는 조건

## E. 모드가 처음 나오는 표
콘텐츠 모드마다 “처음 권장·필수로 만나는 장” 하나와 “나중에 깊어지는 장”

## F. 보상·제출 정책 요약
`docs/MODPACK.md` 눈금을 다시 확인하고, 예외가 있으면 적는다.

## G. 지금 책과 무엇이 달라지는지
유지 / 합침 / 없앰 / 새로 만듦을 표로.
이미 깬 퀘스트 이전은 “새 책이므로 처음부터”로 가정해도 된다(그렇게 적는다).

## H. 나중에 만들 일 목록 (우선순위)
1) 생성기·번역 형식에 맞는 시작하기 + 첫 튜토리얼 장 골격
2) 나머지 본편
3) 번들
4) 도감에 넣을 품목 표
5) 퀘스트가 잡지 못하는 Realism Survival 행동이면, 감지용 작은 추가 모드가 필요한 목록

# 일하는 방식
- 먼저 A~G 설계만 제출한다. 승인 전에 퀘스트 파일을 수백 개 쓰지 않는다.
- 모르는 부분은 질문보다 **가정 목록**을 설계 맨 위에 적는다.
- Sunlit Valley를 그대로 베끼는 것이 목적이 아니다.
  참고할 점은 “처음 탭을 접어 두기”, “분량감”, “모아 제출하며 끝나는 엔딩”이다.
- 톤: 생존은 진지하게, 초반은 읽기·체크로 문턱을 낮춘다.

# 잘된 설계의 기준
- 설명집에 있는 콘텐츠 모드가 본편 어딘가에서 의미 있게 나온다(순수 편의 모드는 예외).
- 시작하기만 읽어도 “지금은 튜토리얼만 보면 된다”고 이해한다.
- 본편 클리어와 도감 엔딩의 경계가 분명하다.
- 모드 설명집에 있는 모드와, 위에 적은 진행·밸런스 방향을 지킨다.
```

```text
승인된 설계(위 대화의 A~G)대로 FTB Quests를 구현한다.

- 기준 폴더: pack/config/ftbquests/
- 생성: python tools/generate_ftbquests.py (README대로)
- 형식: JSON5, 제목·설명은 lang 폴더, 아이콘은 아이템 객체, 아이디는 부호 있는 긴 정수용 16진수
- 한국어 번역을 먼저 채우고, 영어(en_us)는 같은 키로 맞춘다
- 한 번에: 시작하기 + 새 튜토리얼 첫 장 + 큰 탭·장 골격 정도만
- 도감 전체는 품목 표가 정해지기 전에는 자리만 잡거나 소수만

월드 물·백팩·워프·벌목·땅 주장에 대한 팩 방향은 docs/MOD_CATALOG.md를 따른다.
```

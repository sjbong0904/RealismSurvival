## 기록 갱신 규칙

- 회차가 끝나면 상태, 보고서 링크, 남은 질문을 갱신한다.
- 수정 방향이 사용자와 합의되면 상태를 `합의`로 바꾸고 결정의 범위와 날짜를 기록한다.
- 수정 적용 후에는 실제 변경 위치와 재검토 결과를 추가하고, 확인되지 않은 영향은 남은 항목으로 유지한다.
- `완료`는 검토 목록과 증거가 정리된 상태를 뜻한다. 발견사항이 없거나 모든 제안이 구현됐다는 뜻은 아니다.

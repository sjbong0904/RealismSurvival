# 전수 검토 11 — 플레이어 UI·발견 가능성·한국어

- 검토일: 2026-10-21
- 범위: 시작 안내와 HUD·퀘스트·JEI/Jade·지도·상점의 정보 발견성, 커스텀 모드 및 핵심 외부 모드 한국어 적용 구조
- 증거 수준: 리소스·설정·문서·문자열 정적 확인. 게임 내 폰트/잘림/화면 배치/키 입력은 미확인.

## 요약 결론

팩에는 HUD, 퀘스트, JEI/Jade, 지도와 핵심 모드용 한국어 리소스가 다수 준비되어 있고, FTB Quests의 기본/대체 언어도 `ko_kr`로 지정되어 있다. 사용자가 한국어로 플레이할 때의 기본 방향은 잘 잡혀 있다. 다만 번역팩 활성화는 설치/사용 지침에 의존하며 기본 적용이 배포 설정에서 보장되는지 확인되지 않았다. 더 구체적으로 FTB Quests의 `en_us` 데이터 경로에 한국어 설명이 들어간 사례가 있어 영문 설정의 품질과 언어별 정본 구분이 흐려져 있다. 퀘스트 행동 감지 한계와 수동 체크 안내는 이미 08번에서 별도로 기록했다.

## 확인 결과

- 커스텀 모드: `src/main/resources/assets/realismsurvival/lang/ko_kr.json` 및 `en_us.json` 존재. 상점 진입 실패·NPC 이용 안내, 물/온도계 툴팁 등이 정의되어 있다.
- 오버레이: `pack/lang-ko/`에 40여 모드 네임스페이스 번역 소스, `pack/resourcepacks/rs-korean/`에 생성된 리소스팩이 있다. JEI, FTB, Q Shop, SG Economy, Serene Seasons HUD, 지도·월드맵 등이 포함된다.
- 빌드 흐름: `scripts/build_korean_resourcepack.py`는 모드 JAR의 기존 한국어와 오버레이를 합쳐 산출물을 만들고 `run/resourcepacks`에 복사한다. 문서는 플레이어가 한국어 설정과 리소스팩 활성화를 별도로 하도록 안내한다.
- FTB Quests: `pack/config/ftbquests-client.json5`와 `quests/data.json5`의 편집/대체 언어가 `ko_kr`이다. 퀘스트 현지화 파일은 ko_kr과 en_us 디렉터리에 모두 존재하지만 en_us의 일부 본문이 한국어로 복사되어 있다.
- 인터페이스 데이터: SeasonHUD 위치는 좌상단, 계절/날짜 표시가 켜져 있고 미니맵 통합은 꺼져 있다. RS 온도계 HUD와 함께 표시하는 목적이 설정 주석에 적혀 있다. 실제 해상도별 겹침은 미검증이다.
- 검증 도구: `scripts/verify_lang_ko.py`는 모드별 번역 키 커버리지를 JAR의 en_us/ko_kr 및 오버레이와 비교하도록 작성되어 있다. 이 회차에서는 실행하지 않았고, 현재 프로젝트 의존성과 실제 배포 산출물 버전을 기준으로 한 최신 결과는 없다.

## 발견사항

### 11-1 / P1 / 한국어 리소스팩의 적용 여부가 사용자 단계에 남아 있음

- 현재 동작: 별도 리소스팩을 `resourcepacks`에 넣고 활성화해야 모드 번역 오버레이가 완전히 적용된다. 현재 트리에서 기본 활성화를 보장하는 팩 메타 설정은 확인되지 않았다.
- 플레이어 영향: 언어를 한국어로 바꾸어도 일부 모드 UI가 영어로 남을 수 있다. 처음 실행한 사용자는 리소스팩이 별도라는 점을 놓치기 쉽다.
- 권장 조치: 13번에서 배포 플랫폼별 기본 리소스팩 활성화 방식을 확인한다. 강제 활성화가 적절하지 않으면 첫 실행 안내와 메인 퀘스트에서 한국어 리소스팩 경로를 분명하게 알린다.
- 확신도: 현재 사용 안내는 높음, 배포본 기본 적용 여부는 미확인.

### 11-2 / P1 / en_us 퀘스트 번역 경로에 한국어 텍스트가 섞임

- 위치: `pack/config/ftbquests/quests/lang/en_us/all.json5`, `chapters/*`와 ko_kr 대응 파일
- 현재 동작: 확인한 설명 예시(민물·Oritech·의약품·넵튜늄·지도/JEI 과제)가 영어 대신 한국어로 들어 있다.
- 플레이어 영향: 영어를 선택한 사용자에게도 한국어 퀘스트 설명이 나타날 수 있고, 원본/번역의 수정 방향이 혼동된다.
- 권장 조치: ko_kr 파일을 한국어 정본으로 유지하고 en_us는 실제 영어를 제공하거나, 영어 지원 범위가 없다면 번역 분리 정책을 명시하고 기본 fallback 동작을 의도적으로 설정한다. 문서와 게임 설정은 13번에서 함께 갱신한다.
- 확신도: 예시 문장 기준 높음.

### 11-3 / P2 / 번역 커버리지 수치가 최신 배포 조합으로 검증되지 않음

- 현재 동작: 검사 스크립트는 있으나, 현재 확인 자료에는 최신 실행 결과가 없다. 오버레이 생성 대상 목록과 실제 의존 JAR 이름 버전이 어긋나면 모드가 누락되거나 오래된 키를 기준으로 남을 수 있다.
- 권장 조치: 13번에서 실제 배포 모드 목록 및 정확한 JAR을 기준으로 커버리지 보고서를 생성하고, 누락 키와 미번역 문자열을 우선순위화한다. 자동 번역된 설명은 단순 키 충족과 자연스러운 한국어 검수를 구별한다.
- 확신도: 높음.

### 11-4 / P2 / HUD·퀘스트·모드 안내의 실제 화면 검토가 남음

- 현재 동작: 좌상단에 계절·날짜와 RS 시간/온도 HUD를 모으도록 되어 있다. 퀘스트는 FTB UI 및 사용법 과제를 포함한다.
- 플레이어 영향: 화면 해상도·UI 배율·긴 한국어 문구에 따라 겹침이나 잘림이 발생할 수 있지만 정적 설정만으로 판정할 수 없다. FTB 설명에서 일부 키 설명은 영문 원문이거나 번역이 어색할 수 있다.
- 권장 조치: 14번 실제 플레이에서 기본 해상도와 낮은 UI 배율/큰 UI 배율을 포함해 HUD, 퀘스트 설명, 상점 툴팁, JEI 검색/레시피 화면을 확인한다.
- 확신도: 위험 가능성은 보통, 실제 결함 여부는 미확인.

## 정리 방향

1. 한국어 정본은 `ko_kr` 퀘스트 파일과 `pack/lang-ko` 오버레이로 분명히 한다.
2. 영어 퀘스트 파일은 영어로 번역하거나, 영어 미지원 정책에 따라 fallback을 의도적으로 맞춘다.
3. 배포 산출물에는 리소스팩 설치/활성화 안내를 포함하고 가능한 경우 기본 적용 여부를 패키지별로 확인한다.
4. 13번에서 현재 JAR 목록 기준 키 커버리지 수치를 확인하고, 14번에서 실제 화면을 검수한다.

## 후속 회차 연결

- 13번: 리소스팩 산출/배포, 지원 언어, 번역 검증 스크립트와 문서 정합성.
- 14번: 실제 HUD 겹침, 한국어 UI 잘림, 첫 실행 온보딩 및 상점/퀘스트 UX.
- 별도 재검토: 퀘스트 자동 감지/설명 문제는 08번 제안 목록의 수정 방향 확정 후 해당 범위 재검토.

# 계절 공급소 (상자 GUI + Easy NPC + SG Economy)

인벤토리 아래 **골드**는 SG Economy UI를 그대로 쓴다.  
구매·매입은 같은 더블 상자 GUI다. SG Economy가 있으면 SG 잔액이 정본이고, RS가 Q Shop `coins`를 SG 잔액에 맞춘다 (D-06).

## 플레이어 이용

1. 공급소 상인 **우클릭** → 상자 허브. 에메랄드 **구매** / 금괴 **매입**을 고른다.
2. **구매**: 카탈로그 칸을 클릭하면 산다(쉬프트 클릭은 8회). 가격·오늘 한도·잔액은 아이템 툴팁과 아래 금 조각에 표시된다. 화살은 허브로, 지도는 다음 페이지다.
3. **매입**: 가운데 3×3 임시 칸에 물건을 올리면 서버가 견적을 계산해 칸 색(초록 전부·노랑 일부·빨강 거절)과 툴팁(개당 가격·거절 사유)을 보여준다. 아래 금 조각에 받을 금액이 뜨고, 에메랄드를 눌러 확정한다. 지급 실패 시 칸을 원상 복구한다. 남은 물건은 창을 닫으면 돌려받는다(인벤이 차면 발밑에 떨어짐). 화살은 허브로 돌아간다.
4. `qshop open supply_post...` 직접 열기 명령은 차단되며 NPC를 이용하라는 안내가 표시된다.
5. 잔액은 상자 안 금 조각 / 인벤토리 골드 / `/coins get`

### 매입 규칙 (가격 정책, D-05 1단계)

- **매입 가능 = 거절 사유가 없는 모든 품목**. 상인 종류와 관계없이 받는다. 계절 카탈로그·`SupplyStock`에 있는 품목은 기존 가중치를 쓴다(자기 분야는 판매가의 약 3분의 2, 다른 분야는 그 값의 약 85%). 목록에 없는 물건은 낮은 고물 가격이며, 전문 분야가 아니면 같은 85% 할인을 받는다.
- 목록에 있어도 거절: 이름 변경·마법부여·`custom_data`가 붙은 고유 스택, 손상된 장비, `#realismsurvival:supply_unsellable` 태그(명령·구조 블록, 드래곤 알 등).
- 개당 가격 = 매입 라인 가격 ÷ 라인 수량. 총액은 정확히 합산 후 한 번만 내림한다.
- 일일 한도 = 라인 수량 × `playerLimit` (개), 플레이어별·품목별, 오버월드 하루 기준. 플레이어 영구 데이터에 기록.
- `supplyCounterEnabled = true`(기본)면 매입은 상자 계산대만 쓰고, 한도를 두 번 쓰지 않는다. `false`면 매입 칸이 허브에서 빠진다.
- 가판대 수는 그대로이고, 각 자리는 식량·무기·물약·광물 상인 중 하나다. 상인이 **파는** 물건은 그 분야만이다. 식량은 작물·요리·축산물(가죽·양털), 무기는 검·활·화살·방패·갑옷·횃불·모닥불, 물약은 물·필터·소금·양조 재료·얼음, 광물은 석탄·숯·원석·구리 주괴다. 오버월드 날짜가 지나면 진열이 단계로 늘어난다. 0일 기초(돌·가죽·구리), 12일 철, 32일 금, 64일 다이아, 96일 네더라이트. 이전 단계는 남고, 검·갑옷은 그 단계의 장비만 추가된다. 곡괭이와 금 주괴·철 주괴·네더라이트 주괴·증류기·필터 기계는 상점에서 팔지 않는다. 다이아와 네더라이트 조각은 해당 단계부터 하루에 1개다. **매입**은 모든 상인이 전 품목을 받되, 자기 분야가 아니면 더 싸다. 같은 기후·같은 계절에서는 매입이 판매보다 싸다
6. 계절과 기후에 따라 값이 바뀐다. 같은 물건이라도 그 고장에서 귀하거나 그 계절에 더 필요하면 비싸다. 가게 형태도 둘을 함께 따른다. 온대는 박공 가판, 건조는 난간 있는 평지붕, 한대는 눈 덮인 오두막, 열대는 잎 지붕이다. 식량은 열린 진열대, 무기는 뒷벽 작업장, 물약은 세 면이 막힌 방, 광물은 낮은 돌담 창고다. 이미 세워진 가판대는 바뀌지 않는다

## 월드젠

- Feature: `realismsurvival:supply_post` (`#minecraft:is_overworld`). 바다·해변은 제외. 온대·숲 140, 열대·그 밖 육지 200, 건조 300, 한대 400청크당 1회. 바닥은 가장 낮은 땅에 붙이고, 한 칸 높은 부분만 깎는다. 더 가파르면 그 시도 안에서 네 방향으로 평평한 자리를 찾는다.
- 스톨 중앙 `supply_post_marker` 블록이 청크 로드 후 Easy NPC(`easy_npc:villager`)를 스폰하고 태그 `rs_shop`을 붙인다
- 오픈 워터를 두지 않는다 (건식 가판대만). 새로 생기는 가판대만 기후·분야별 형태를 쓴다

## 수동 상인 배치 (크리에이티브)

1. Easy NPC로 상인 생성 (거래는 비워 두거나 None)
2. 엔티티에 태그 추가: `/tag @e[type=easy_npc:villager,limit=1,sort=nearest] add rs_shop`
3. 또는 기능 블록 `supply_post_marker`를 설치하면 근처 상인을 자동 확보한다

## 설정 위치

| 파일 | 역할 |
|------|------|
| `pack/config/realismsurvival/supply_shop_seasons.json` | 기후·계절별 구매/매입 품목·가격 (런타임: `config/realismsurvival/…`) |
| `pack/config/qshop/currencies.json` | 통화 표시명 (`coins` = 골드) |
| `pack/config/qshop/shops/supply_post.json` | 초기 템플릿 (서버 시작·계절 변경 시 시즌 컨픽이 덮어씀) |
| `pack/config/sg_economy-*.toml` | 인벤 골드 UI |

새 월드가 Q Shop 템플릿을 안 가져오면 `/qshop overwrite`(OP)로 `config/qshop` → 월드 `serverconfig/qshop`을 덮어쓴다.

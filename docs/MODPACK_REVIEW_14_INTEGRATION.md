# 전수 검토 14 — 통합 진행 시나리오·회차 간 회귀 위험

- 검토일: 2026-10-21
- 범위: 신규 월드 첫날부터 본편/번들, Oritech 기반시설, 탐험·필수 이동 체인, 도감/완벽 엔딩까지 앞선 00–13 검토 결과를 이어서 검토
- 방법: 소스·설정·퀘스트·앞선 검토 보고서를 기반으로 한 정적 플레이 시나리오 추적
- 제한: 신규 월드에서 실제로 플레이하지 않았고, 퀘스트 버튼·GUI·드롭 확률·시간/TPS는 측정하지 않았다. 따라서 “통합 시나리오 정적 검토” 완료이며 런타임 회귀/플레이 실측은 미완료다.

## 요약 결론

팩의 의도된 플레이 흐름은 현실 생존 튜토리얼 → 농사/요리 → 탐험과 시설 → 후반 이동/위험 → 기본 자동화 → 번들 → 장기 도감/완벽 엔딩이다. Oritech은 초중반 선택 체험으로 시작해 중반 가공·후반 공방 확장으로 퍼져 있어 별도 기술 모드를 갑자기 후반에 몰아넣지 않는다. 60시간은 전체 클리어가 아니라 핵심 튜토리얼 안내 목표이며 도감/완벽 엔딩은 더 긴 별도 장기 목표로 설계했다. 실제 시간 데이터는 없다.

초중반 다이아몬드는 II장 첫 씨앗 과제 뒤 해금되므로 일반 생존 진행보다 늦지 않다. 전체 흐름에서 가장 큰 단일 진행 리스크는 C4의 바다 물고기 제출 이후 희귀 Neptune’s Bounty로 얻는 넵튜늄 잉곳이 워프스톤/워프 두루마리와 장 마무리에 연결되는 점이다. 보급소는 희귀 월드젠이지만 퀘스트가 선택이라 필수 진행을 막지 않는다. 생존 물·계절·도감 문구와 수동 UI 과제는 안내/발견성 문제를 일부 남긴다.

## 통합 우선순위

### P1 — 필수 진행의 낚시 RNG 관문 완화 여부 결정

C4-10 어종 두 종은 보통 해양에서 적어도 세 목표가 겹쳐 바이옴 순회보다 입질/제출 부담이 핵심이다. 그 다음 넵튜늄 잉곳을 요구하고, 희귀 Neptune’s Bounty가 장 마무리와 Perfection 시작으로 이어진다. 긴 수집 목표는 장기 플레이에 적합하지만 필수 진행은 운에 맡겨진다. 09번 제안대로 첫 접근용 보장 잉곳을 퀘스트/대체 획득으로 제공하거나 워프스톤 대체 경로를 둘지 결정이 필요하다.

### P1 — 실제 배포 조합이 없으므로 “처음 플레이” 기준선은 개발 프로필

기본 `runClient`는 `localRuntime` 기반 개발 실행이다. 정식 사용자 설치 패키지와 정확한 필수 모드 조합이 고정되지 않아 위 흐름은 개발 프로필을 가정했다. 선택 의존성, 리소스팩 자동 활성화, 새 월드 설정은 13번의 배포 프로필 결정을 거쳐야 실제 신규 플레이어 경험이 된다.

### P2 — 처음 알게 되는 행동과 완료 판정의 간극

수원 음용/아이템 제출, GUI 열기, 공방 연결의 수동 체크가 설명이나 실제 행동과 일치하지 않는 사례가 있다. 초보자는 “행동했는데 왜 안 끝나는가” 또는 반대로 “아직 실제로 쓰지 않았는데 끝났다”고 생각할 수 있다. 08번에서 실제 감지 가능한 행위로 바꾸거나 설명을 소유/확인 목표로 고칠 항목을 별도로 기록했다.

### P2 — 완벽 엔딩으로 넘어가기 전에 중간 보상 가치가 떨어질 수 있음

도감 보상은 세부 퀘스트의 폭을 넓히지만, 골드·경험치·기본 재료가 누적되어 후반 플레이어에게 이미 풍부한 보상일 수 있다. P-10 완벽 보상의 목적 문서와 실제 지급 내용이 다른 것도 발견했다. 08번에서 퀘스트 지점별 예상 발전도 및 기념 보상 여부를 정리하고, 실제 플레이 인벤토리 기록으로 결정해야 한다.

## 다른 회차와의 연결 판정

- 00–01: 대상 구성은 개발 기본 프로필이며 배포 여부/애드온 공개 단위는 아직 결정되지 않음.
- 02–05: 생존·농사·레시피·외부 모드 연결은 세부 보고서 발견사항을 유지한다. 정적 재료 경로는 확인됐지만 실제 진행속도/성장감은 플레이 미측정.
- 06–08: 다이아 진행 위치는 적절하다. 퀘스트 양은 현재 844개로 장기 목표를 받치지만 60시간은 측정치가 아니다. 문안/보상/자동감지 개선은 미반영.
- 09–10: 탐험 자원 연결은 대부분 맞으나 넵튜늄 RNG 게이트가 남아 있다. NPC 진입은 코드상 구현되지만 GUI와 지갑 왕복은 실제 미확인.
- 11–13: 한국어 리소스는 존재하나 배포 적용·영어 퀘스트 경로·설치 패키지 정책은 정리 필요. `MODPACK.md`는 현재 상태 요약을 추가했지만 오래된 계획 문서를 전수 정리하지 않았다.

## 최종 평가

현재 구성은 생존/탐험을 중심에 두고 농사·음식·작은 자동화·장기 수집을 연결하는 모드팩 콘셉트와 대체로 맞는다. 다이아가 너무 늦다는 진행 순서 문제는 현재 구현에서 수정된 상태다. 초중반 Oritech 기반시설은 선택형으로 일찍 소개되고, 본편 이후 수집 목표량은 충분하다. 완성도를 가장 크게 좌우할 다음 결정은 (1) 필수 워프 이동의 넵튜늄 RNG 보장, (2) 퀘스트 문안/감지와 보상 가치 정합, (3) 배포 모드팩과 한국어 적용을 실제 신규 사용자 기준으로 고정하는 일이다.

이 보고서는 00–14 각 정적 검토 문서의 현재 결론을 통합했다. 신규 월드 플레이, 다중 플레이어 거래, 시간/TPS, 실제 GUI 레이아웃은 검증하지 않았으므로 정적 검토 완료를 플레이 테스트 통과로 간주하면 안 된다. 실행 검증을 포함한 후속 작업은 위 세 결정과 배포 프로필이 구체화된 뒤 별도 시나리오로 진행한다.

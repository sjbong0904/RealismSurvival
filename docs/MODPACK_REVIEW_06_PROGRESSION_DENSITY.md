# 전수 검토 06 — 성장 곡선·콘텐츠 밀도

검토일: 2026-10-21  
검토 기준: 현재 퀘스트 전체 목록·모드팩 개요·기본 진행표의 구조 정적 검토. 게임 플레이 시간을 실측하지 않았다. 퀘스트 의존선의 정확한 누락/순환은 07번에서 별도 추적한다.  
범위: 초반 생존에서 농사/요리·탐험·자동화, 후반 통합 공방, 본편 이후 도감·완벽 엔딩으로 이어지는 성장 단계와 각 콘텐츠 밀도.

## 요약

큰 흐름은 생존(I) → 농사·부엌(II) → 바이옴/구조물 탐험(III) → 위험 지역·유물·넵튜늄·이동(IV) → 수송·저장·급수 자동화(V)다. Oritech은 II에서 선택형 기초 발전, III에서 기계 가공, IV 이후 저장 장치, V 뒤 통합 공방으로 나눠 열어, 자동화를 후반에 한꺼번에 소개하지 않으려는 설계가 보인다. 본편과 번들 이후에는 작물·음식·물고기·바이옴·생물·광물·유물 수집과 Perfection을 별도 장기 목표로 둔다. 이는 “안내를 익히는 약 60시간”과 “전체 수집·완성은 더 오래 걸림”이라는 사용자의 목표와 방향상 맞다.

다만 현재 정적 문서는 실제 제공량과 계획치가 섞여 있다. `QUEST_LIST.md`는 844개(본편 162, 번들 111, 도감/완벽 571)라고 기록하지만, `MODPACK.md`에는 목표 총량 1,000~1,100, 도감 700+, 추가 40~60시간 등 현재 목록에서 재산출한 근거와 맞지 않는 계획 숫자가 남아 있다. 현재의 60시간 또한 플레이 측정이 아니라 설계 예산이다. 그리고 첫 다이아몬드를 IV장 목표로 두는 부분은 현실 플레이에서 일찍 얻을 수 있어 07번 순서 검토로 넘긴다.

## 발견사항과 수정 방향

### 06-1 — 기본 자동화 진입 전에 Oritech을 나눠 소개하는 흐름은 자연스럽다 (양호, 실 플레이 확인 필요)

Oritech의 기본 발전기·전력 화로는 농사 장에서 선택으로 먼저 열리고, 분쇄기/전력 관은 탐험 장에서 실제 가동 목표로 이어진다. 플라스틱이 필요한 배터리는 IV장 이후 선택이고, 급수/부엌/수확물 자동화가 생긴 V장 뒤에 전력 공방 연결을 둔다. 새 기계를 후반에 한꺼번에 던지기보다 작은 전력망을 일찍 경험하고 나중에 설비와 결합하려는 단계성이 명확하다. 선택 갈래라 기본 생존/탐험 진행도 막지 않는다.

**유지 방향:** 기초 전력은 선택 체험, 기본 수송/급수 자동화는 본편 기술로 구분한다. 첫 Oritech 기계의 비용/성능이 초반 생존을 압도하는지와 기계 사용 설명의 가독성은 08·14에서 검증한다.

### 06-2 — 60시간 목표는 현재 숫자만으로 보장되지 않으며, 문서의 계획량이 실제 목록과 어긋남 (P1, 기획 신뢰도)

현재 목록 기준 본편 162개(시작 15 + 튜토리얼 I~V 147), 번들 111개, 수집/완벽 571개로 합계 844개다. 모드팩 개요에는 목표 총량 1,000~1,100개와 도감 700+개를 적었고, 완료까지 추가 40~60시간을 제시한다. 반면 본편·번들 273개와 수집 571개를 현재 산출물에서 확인했다. 실제 소요 시간은 탐험 거리, 제작 대기, 협동 여부, 퀘스트를 얼마나 읽는지에 좌우되며 현재 문서의 시간은 실측값이 아니다.

**수정 방향 제안:** 13번에서 실제 퀘스트 파일로 챕터/태스크 수를 자동 재산출해 문서 목표 숫자와 구분한다. 사용자가 정한 기준을 “핵심 진행 안내 약 60시간, 전체 도감/완벽은 그보다 상당히 오래”로 명확히 쓰고, 남은 수집 시간은 플레이 기록 전까지 예상치 또는 미측정으로 표시한다. 퀘스트 수만 늘려 시간을 맞추지 말고 콘텐츠 반복감/단계적 의미를 본다.

### 06-3 — 본편 이후 목표는 많지만, 상당수는 품목 1개 보유/방문식 수집임 (P2, 엔드게임 깊이)

작물 75, 음식·음료 135, 물고기 57, 바이옴 137, 생물 65, 광물 39, 유물 53, Perfection 10개로 큰 수집량은 갖췄다. 각 도감 과제는 대체로 하나의 아이템 보유·먹기·처치·방문이고, 장기성은 품목 다양성과 환경 접근에 의존한다. 전체 올클리어에 장시간이 필요한 것은 사용자의 목표와 맞지만, 작업 목록만 길게 느껴지면 최종 구간의 체감은 깊어지지 않을 수 있다.

**수정 방향 제안:** 전부를 더 어렵게 만들 필요는 없다. 도감 중간 달성률 보상은 가볍게 유지하고, 100% Perfection에서 여러 시스템을 실제로 함께 사용했다는 선택형 종합 과제를 둘지 검토한다. 탐험/수집이 주된 즐거움이면 희귀품 보유보다 해당 바이옴·생태계에서의 발견 기록을 중심으로 한다. 보스/강제 전투를 엔딩 게이트로 만들지 않는 현재 방향은 유지한다.

### 06-4 — 다이아몬드와 몇몇 이동/기술 과제의 단계가 실제 평균 획득 순서보다 늦을 수 있음 (07번 이관)

IV장 심층 탐험 마무리가 “첫 다이아몬드”를 요구하지만, 일반 플레이에서는 광산 채굴, 구조물 전리품, 높이/장비에 따라 III장 또는 더 이른 때에 다이아를 획득할 수 있다. 퀘스트가 실제 성취보다 뒤늦게 “첫 발견”을 인정하거나, IV장 마무리에서 요구하는 다이아가 별도 소모/제출이라면 보유만으로 완료되지는 않는다. 다이아 상자는 V장에서도 명시적으로 필수 조건이 아니다.

**수정 방향:** 07번에서 다이아 과제를 채굴/광산 안내 단계로 앞당길지, IV장에서는 더 깊은 곳의 다이아 장비/응용으로 바꿀지 검토한다. 다른 후반 배치 자원(철·금·웨이스톤·넵튜늄·유물)도 통상 획득 시점과 퀘스트 순서를 함께 대조한다.

### 06-5 — 번들 단계와 본편 마무리가 콘텐츠를 묶지만, 60시간은 현재 플레이테스트 없이 확정할 수 없음 (P2)

튜토리얼 장 수와 별도로 생존·부엌·목축·탐험·공방 번들이 본편 후반의 종합 제출을 맡는다. 본편 후에는 광범위한 수집 목표가 분리되어 사용자가 원하는 장기 엔딩 구조를 갖춘다. 그러나 챕터 수/태스크 수는 평균 플레이 시간을 직접 설명하지 않으며, 지금 수치로 튜토리얼이 60시간에 “자연스럽게” 전달되는지는 확인되지 않는다.

**수정 방향 제안:** 14번에서 새 월드 플레이 기록을 튜토리얼+번들 목표, 전체 수집 목표로 분리해 남긴다. 예상 플레이어가 어느 시점에 과제를 만나고 실제로 다음에 무엇을 하는지 기록한다. 첫 회차 플레이 로그가 생기기 전까지 60시간은 의도/예산으로 유지한다.

## 회차 결론

성장 구조의 핵심은 명확하고, Oritech을 선택형 초중반 기반시설에서 후반 공방 확장으로 자연스럽게 이어 붙인 점은 현재 구성에 잘 맞는다. 전체 수집량도 오래 플레이할 목표를 제공한다. 먼저 고칠 부분은 **06-2 현재 목록과 맞지 않는 전체 퀘스트 수/시간 문구를 정리**, **06-4 다이아·이동/희귀 자원의 퀘스트 도달 시점을 재배치 검토**, **06-3 수집량과 종합 숙련 목표의 균형**이다. 실제 60시간 적합성과 장기 엔딩의 반복감은 14번 플레이 기록으로 확정한다.

# 회귀 확인표 (패치 7.3 · 8단계)

지원 조합: **Minecraft 26.1.2 / NeoForge 26.1.2.122 / Java 25** (`MODPACK_PATCH_STAGE0.md` 0.1).
버전·모드 목록·생존 수치·퀘스트 원본을 바꿨다면 아래 **자동 선행 확인**을 모두 통과시킨 뒤, 바뀐 영역의 수동 항목을 다시 본다.
결과는 항목 옆에 `통과 / 실패(메모) / 보류`로 적고, 날짜와 빌드(버전·커밋 또는 백업 이름)를 맨 아래 기록표에 남긴다.

## 자동 선행 확인

| 명령 | 기대 결과 | 막는 문제 |
|------|-----------|-----------|
| `.\gradlew compileJava` | 성공 | 컴파일 오류 |
| `.\gradlew runGameTestServer` | `All N required tests passed` (현재 19) | 갈증·음용·리스폰·체온·수질·가마솥·물고기 양동이·디스펜서·증류·신선수 정체·기계 유체 입력 |
| GameTest 로그에서 `Couldn't parse` / `Missing tag` / `Unbound values` 검색 | 0건 | 다른 모드 ID 오타·없는 아이템·태그 바인딩 문제 (2026-10-21: BoP 바이옴, `sun_crops`, `any_artifact`, `special_fish_hook`, 훅 재활용 레시피 3개 수정) |
| `python tools/sync_bridge_recipes.py --check` | `OK: 79 canonical, 79 pack` | JAR ↔ 데이터팩 브리지 레시피 불일치 |
| `.\gradlew writeRuntimeJarList` 후 `python tools/scan_missing_ko_kr.py --jar-list build/reports/runtime-jars.txt --fail-on-missing` | 종료 코드 0, RS 소유 ko_kr 누락 0 | 한국어 키 누락 (6.2) |

GameTest 프로필은 선택 모드(Serene Seasons, 팩 콘텐츠 일부)를 자동 제외한다. SS 연동은 아래 8.3에서 수동으로 본다.

## 8.1 신규 월드 / 서버 시작

- [ ] `runClient` 새 월드 생성: 시작 로그에 `ERROR` 중 RS·브리지·퀘스트 관련 0건
- [ ] `runServer` 전용 서버 기동 + 클라이언트 접속: 누락 모드 경고 없음, `Pack-stack detection` 줄이 예상 모드와 일치
- [ ] 데이터팩 `rs-item-bridges` 활성, 퀘스트북 열림(844개), 한국어 리소스팩 + 언어 `ko_kr`에서 퀘스트·JEI·Jade 한글 표시
- [ ] 첫 접속 T0-02 안내대로 한국어 설정을 따라 할 수 있음

## 8.2 생존 수치와 세이브 (1단계)

- [ ] `tickInterval` 1 / 20 / 200에서 물속 갈증 회복, 탈수·동상·열사병 초당 피해가 같은 수준
- [ ] 강물 맨손 음용 ≈ 병의 25%(`worldDrinkBottleFraction`), 수질 효과(구토 등)는 그대로
- [ ] 갈증/체온 기능을 끄면 자연 회복이 그 지표 때문에 막히지 않음
- [ ] 잘못된 설정(임계값 역순, 지속시간 0)에서 경고 1회 + 보정 동작
- [ ] 죽음·재접속·차원 이동 후 갈증/체온/수질 데이터 유지·초기화가 설계대로

## 8.3 농사와 계절 (2단계)

- [ ] SS 설치·정상: 외부 계절 규칙 사용, 작물 계절 태그(spring/summer/autumn) 적용
- [ ] SS 설치·조회 실패(예: 비오버월드 차원): 경고 1회 후 RS 달력 규칙으로 일관 전환, 반복 로그 없음
- [ ] SS 미설치: RS 달력 + RS 작물 규칙
- [ ] 성장 배율 최대 조합(기후·빛·계절·수분 최적)이 `cropGrowthMultiplierMax`(기본 1.75)를 넘지 않음
- [ ] `sun_crops`(밀·당근·감자·비트·수박/호박 줄기·토치플라워·주전자풀·달콤한 열매) 빛 규칙이 실제로 걸림 (하늘빛 0–5에서 성장 정지)
- [ ] 표본 작물 3종(밀, FD 작물 1, BoP/외부 1)의 성장 시간 기록

## 8.4 자원 / 기계 흐름 (3단계)

- [ ] 바닷물 양동이 화로 증발: 가득 = 소금 2, 1/3 = 소금 1, 빈 양동이가 연료 칸(비었을 때) 또는 입력 칸으로 돌아오고 호퍼로 빼낼 수 있음
- [ ] 소금 → 필터 카트리지 2개, 모래 필터 경로와 비교해 소금 경로가 보상이 있음
- [ ] 물 필터·증류기 입출력, 출력 칸 막힘 시 멈춤(소실 없음)
- [ ] Oritech 신선/증류수 대체 공정이 원본 고체 재료·수량·시간 유지
- [ ] 화로·디스펜서·얼음 깨기·녹이기·스펀지·물고기 양동이 어느 경로에서도 열린 `minecraft:water` 칸이 남지 않음 (`MIXIN_POLICY.md` 1–6)

## 8.6 상점 단독 / 다인 거래 (5단계)

- [ ] 공급소 NPC 일반 우클릭 → Q Shop 구매 화면 + 매입 안내 액션바
- [ ] 웅크리고 우클릭 → RS 매입 계산대. 슬롯 색: 초록(전량) / 노랑(일부) / 빨강(거절), 툴팁에 개당 단가·사유
- [ ] 거절 사유: 매입 안 함, 이름/커스텀 데이터/인챈트(고유), 손상, 일일 한도, `supply_unsellable` 태그
- [ ] 확정: 아이템 제거 + coins 입금 1회, 거절·남은 수량은 계산대에 남고 닫으면 인벤토리(가득 차면 바닥)로 반환
- [ ] 쉬프트 클릭 이동, 8블록 이탈·NPC 사망 시 닫힘 + 반환
- [ ] 일일 한도: 같은 게임 날짜 안에서 누적, 다음 날 초기화, 재접속 후 유지
- [ ] `supplyCounterEnabled=true`일 때 Q Shop 공급소에 SELL 항목 없음 / `false`일 때 기존 SELL 복귀
- [ ] `/qshop open supply_post…`와 `/execute … run qshop open supply_post…`가 일반 플레이어에게 차단, 관리자는 허용
- [ ] 두 플레이어 동시 매입·구매: 잔액 합계 일치, 중복 지급 없음. 재접속 후 SG ↔ Q Shop 잔액 동일

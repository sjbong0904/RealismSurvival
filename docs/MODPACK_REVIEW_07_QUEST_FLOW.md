# 전수 검토 07 — 퀘스트 구조·진행 순서

검토일: 2026-10-21  
검토 기준: 퀘스트 원본 생성 코드(`tools/quest_v1/tutorial.py`), 생성된 챕터 JSON5, 현재 한국어 진행표의 선행 조건·선택/필수 표기를 대조했다. 문장별 교정과 보상 수치는 08번에서 다룬다. 런타임 UI에서 잠금 표시가 어떻게 보이는지는 실행 확인하지 않았다.  
범위: 웰컴과 I~V 본편 진행선, 챕터 간 선행 관계, 다이아/넵튜늄/이동/자동화 순서, 필수 게이트와 선택 분기.

## 요약

퀘스트 구조는 여러 챕터의 첫 과제를 일찍 열어 플레이어가 생존·농사·탐험·자동화 중 다음 관심사를 선택할 수 있게 하고, 각 장의 마무리 퀘스트가 해당 장의 핵심 과제만 묶는다. Oritech 선택 과제는 C2에서 발전기, C3에서 분쇄기 실습, C4에서 배터리, C5 이후 통합 공방으로 단계가 나뉜다. 다이아몬드 과제 `C4-09`는 이름상 IV장 소속처럼 보이지만 실제로는 II장 챕터 JSON에 들어 있으며 `C2-04 첫 씨앗 심기` 뒤 바로 열린다. 따라서 다이아몬드를 처음 얻는 시점이 IV장까지 늦춰지는 구조는 아니다.

현재 진행에서 가장 민감한 게이트는 C4 본편 마무리와 이후 완벽 엔딩이 C4-10의 다섯 지정 바다 어종 중 두 종 제출 → 넵튜늄 획득 → 워프스톤/워프 두루마리 제작으로 이어지는 낚시 체인에 기대는 점이다. 이 체인은 해양 탐험이라는 주제에는 맞지만, 필수 진행을 특정 모드의 낚시 운에 묶을 수 있다. 실제 체감은 09/14번과 교차 확인해야 한다. 또한 다이아 퀘스트의 오래된 ID는 현재 챕터와 어긋나 유지보수 시 혼란을 줄 수 있다.

## 본편 진행선 판정

| 영역 | 현재 선행/요구 | 흐름 평가 |
|---|---|---|
| 시작 → I 생존 | T0 웰컴과 별도로 I 첫 갈증 과제는 바로 열림. I 마무리는 물 비축·온열 팩·외상 키트에 묶임 | 시작 직후 생존 문제를 다루는 자연스러운 병렬 구조 |
| II 농사·부엌 | 달력·밭·씨앗·작물·도구·수프/식사·목축·낚시로 확장. 첫 씨앗 뒤 다이아 과제가 함께 열림 | 생활 기반을 일찍 만들고, 음식 모드에 단계별 진입 |
| III 탐험 | 자연 나침반→BoP 세 바이옴→채집·거점·Lootr·치료. 마무리는 두 거점, 펫 이동, Lootr 10, 구급키트 | 탐험/회수/치료가 하나의 원정 루프로 연결 |
| IV 심층 탐험 | 유물 5종, 광물/철 도구, 바다 낚시 2종, 넵튜늄, 워프 이동, 설원, 진료소 키트 | 새 지역과 장기 이동 수단을 중간/후반으로 확장. 필수 낚시 RNG 영향이 큼 |
| V 자동화 | 상자 티어→파이프/탱크→증류·정수→저장·부엌·수확 자동화. Oritech 연계는 선택 후반 목표 | 기본 공방이 모드 전력 자동화에 종속되지 않아 진입 부담이 덜함 |
| 완벽/엔딩 | 번들·도감/완벽 과제와 생존/가축/탐험/공방 시험을 수렴 | 장기 엔딩은 개별 전투 승리보다 팩 시스템의 넓은 사용을 요구 |

## 발견사항과 수정 방향

### 07-1 — 다이아몬드는 실제로 II장 초반에 열리므로 지나치게 늦지 않음 (확인, 양호)

원본 생성 코드에서 `C4-09 첫 다이아몬드`는 `build_c2()`에 포함되고 `C2-04 첫 씨앗 심기`만 선행한다. 생성된 JSON5도 `tutorial_ii_farm` 챕터에 둔다. 이 과제는 다이아몬드 1개 보유를 확인하고 제출하지 않으며, 보상은 귀환 두루마리 2개와 광물 도감 해금이다. IV장 마무리에서 참조하지만 다이아 획득 자체를 IV장까지 막지 않는다.

이전에 걱정했던 “첫 다이아가 심층 탐험 뒤에만 가능”한 순서 문제는 현재 데이터에는 없다. 다만 `C4-09`라는 식별자가 II장에 위치하는 점은 문서·생성 코드에서 의미상 낯설다. 이를 바꾸면 기존 퀘스트 저장 ID와 진행 데이터에 영향이 있을 수 있다.

**수정 방향 제안:** 현재 퀘스트 ID는 저장 안정성을 확인하기 전까지 유지한다. 코드 주석/생성기에서 이 과제가 II장으로 이동된 이유를 적고, 진행표를 내보낼 때 실제 chapter와 ID prefix를 분리해 표시한다. 신규 월드에서 II장 첫 씨앗 뒤 과제가 잘 노출되는지만 14번에서 확인한다.

### 07-2 — C4 필수 완료가 지정 바다 어종·넵튜늄 낚시 연쇄에 의존함 (P1, 진행 막힘 가능)

C4-10은 Aquaculture 바다 어종 5종 중 2종을 골라 각각 제출해야 열리고, C4-11은 넵튜늄 잉곳을 보유해야 완료된다. C4-15 워프스톤과 C4-16 워프 두루마리가 이어지며, C4-24 심층 탐험 마무리는 C4-16을 요구한다. IV장 마무리와 P-완벽 목표까지 모두 이 이동 체인에 매인다. 어종 목록이 다양하고 넵튜늄은 희귀한 낚시 금속이므로 진행은 모드 판타지에 맞지만, 특정 낚시 모드를 쓰지 않거나 운이 나쁜 플레이어에게 필수 관문이 될 수 있다.

**수정 방향 제안:** 09번에서 바다 어종의 바이옴·미끼/시간·낚시 확률, 넵튜늄의 실제 기대 획득량을 확인한다. 필수 이동/엔딩 재료가 과도한 RNG에 묶인다면 바다 어종은 선택 심화로 옮기거나, 탐험/거래/전리품 중 하나의 보장된 보조 획득 경로를 둔다. 워프스톤 대신 다른 조건으로 IV장 마무리를 열되 워프 이동 제작은 선택 보상으로 유지하는 방안도 비교한다.

> **정정:** 워프스톤은 금 기본 레시피로 만들 수 있어 넵튜늄 낚시 RNG에 묶이지 않는다. `C4-15`의 `C4-11` 의존을 제거했고 `C4-11`은 선택 과제다. 자세한 내용은 `MODPACK_REVIEW_04_RECIPES_ECONOMY.md`의 정정 참고.

### 07-3 — 장별 마무리는 핵심 갈래만 묶고 기술 선택 과제는 필수선 밖에 둠 (양호)

C2 마무리는 요리/수납·목축 쪽에 집중하고 Oritech 기본 발전기/화로는 선택이다. C3의 분쇄기/전력관 실습도 선택이며 탐험장 마무리에서 요구하지 않는다. C4 배터리, C5 후반 자원 탐지기도 선택이다. 반면 C5의 필수 마무리는 Iron Chests/Pipez/탱크를 사용한 급수·부엌·수확 자동화로 완성한다. 이는 기술 모드의 전 과정을 강요하지 않으면서 기반시설을 일찍 만지고 확장하도록 한다.

**유지 방향:** Oritech은 초반 선택 소개 → 중반 실제 가동 → 늦은 공방 통합으로 두되, 선택 표시가 UI에서 명확한지 11번, 기계 레시피 접근성이 적절한지 08번에서 확인한다.

### 07-4 — 독립적으로 열린 챕터와 챕터 마무리 사이의 계층은 명확하나 선행 관계를 플레이에서 확인해야 함 (P2)

첫 퀘스트 설명은 앞 장을 끝내지 않아도 해당 장을 시작할 수 있다고 반복 안내한다. 대신 최종 마무리는 장 안의 여러 필수 과제를 모은다. 이 방식은 플레이어에게 자유를 주지만, 퀘스트북에서 챕터 간 흐름이 한눈에 보이지 않으면 “무엇을 먼저 해야 하는가”가 흐려질 수 있다. 특히 C3 상점은 선택이고 드문 월드젠에 따라 직접 찾으라는 목표여서 메인 진행과 분리되어야 한다.

**수정 방향 제안:** 장 시작에서 “열려 있음”과 “마무리에 필요한 항목”을 구분하는 짧은 안내를 두고, 선택 분기 완료는 본편 마무리 조건에서 제외됐는지 원본/생성 결과를 계속 맞춘다. 11번에서 탭 순서·잠금 표시·분기 시각화를 확인한다.

### 07-5 — 진행표의 ID 체계가 실제 챕터 배치와 다르게 읽힐 수 있음 (P2, 제작/문서 혼선)

다이아 과제가 II장 챕터 파일 안에 있으나 ID는 C4 접두사다. 반대로 C4-24가 해당 과제를 선행으로 참조하고, 광물 도감 시작도 이 ID에 연결된다. 이는 현재 생성 코드의 교차 챕터 참조로 동작하도록 만들어졌지만, ID prefix만 보고 데이터를 손보면 잘못된 파일을 찾기 쉽다. 이전 문서/퀘스트 ID 안정성 때문에 급하게 이름을 바꾸면 저장된 진행도와 충돌할 수도 있다.

**수정 방향 제안:** ID는 내부 안정 키로 취급하고, 사람이 읽는 문서에는 실제 챕터와 논리 그룹을 표기한다. 생성기에는 교차 배치 주석과 별도 매핑을 두고, ID 변경이 불가피할 때는 구 ID에서 새 ID로 저장 데이터 이전 여부를 먼저 검토한다.

## 우선 수정/확인 순서

1. 09번에서 `C4-10 → C4-11 → C4-15 → C4-16`에 필요한 낚시 자원의 실제 접근성과 평균 플레이 부담 확인.
2. 필수 낚시 RNG가 과하다면 바다 어종/워프스톤을 메인 완결의 유일한 관문에서 풀고, 대체 경로를 설계.
3. 첫 다이아 퀘스트는 현재 초중반 개방 상태를 유지하고, ID prefix와 실제 위치를 문서화.
4. 11번에서 장 독립 개방·선택 가지·완료 조건을 UI에서 처음 보는 플레이어가 이해하는지 확인.

## 회차 결론

다이아몬드 과제는 이름에 `C4`가 있어도 II장에 배치되고 `C2-04` 직후 열려 일반적인 초중반 획득 순서에 맞는다. Oritech 선택 갈래도 단계적이다. 주요 리스크는 **C4 마무리/엔딩이 특정 바다 낚시·희귀 넵튜늄·워프 제작에 연쇄 의존**한다는 점이다. 실제 낚시 접근성과 확률을 확인한 후 필요한 경우 한 갈래의 보장 대안을 만든다. 퀘스트 문안과 개별 보상 수량 평가는 08번에서 이어간다.

# 퀘스트 UX 후속 점검

> **역사 기록 (패치 6.6)**: 패치 2–8 이전 점검. 이후 변경(C5 보유형 전환, 넵튜늄 보장, 매입 계산대 등)은 `docs/MODPACK_PATCH_STAGE0.md` 진행 기록을 본다.

이 문서는 생성기와 현재 퀘스트 데이터에 반영된 상태, 후속으로 조사할 UX 과제를 정리한다. 퀘스트의 정본은 `tools/quest_v1/` 생성기이며, `docs/Realism Survival — 퀘스트 진행표 v1.md`와 `docs/QUEST_LIST.md`는 생성 스냅샷이다.

## 수동 확인 과제와 자동 감지

| 퀘스트 | 현재 상태 / UX 문제 | 다음 조치 |
|---|---|---|
| `C3-18` | 주민 거래 발전과제 `minecraft:adventure/trade`로 완료된다. 마을 방문과 Guard Villagers 경비병은 안내일 뿐 완료 조건이 아니다. | 완료. 생성기와 내보낸 퀘스트 파일에 발전과제가 있는지 함께 유지한다. |
| `T0-02`, `T0-10`, `T0-12` | HUD·JEI·도전과제 화면 열기는 현재 안정적인 FTB 과제가 아니다. | 짧은 사용 안내로 두거나 실제 아이템·행동 목표로 교체한다. 화면 열기만 감지하는 훅은 유지 비용 대비 이득이 적다. |
| `T0-07` | 청크 클레임을 현재 감지하지 않는다. | FTB Chunks 이벤트/API를 확인한다. 불가능하면 선택 안내로 두거나 감지 가능한 클레임 관련 목표로 바꾼다. |
| `C3-04` | FTB Chunks 웨이포인트 생성은 추적하지 않는다. | 필수 진행을 막지 않는 선택 탐험 목표로 유지한다. 훅은 FTB Chunks 지원 이벤트/API가 있을 때만 검토한다. |
| `C3-06`, `C3-08`, `C3-12` | 웨이스톤 활성화와 펫 순간이동이 체크마크다. | Waystones·Teleport Pets 이벤트를 조사한다. 안정적인 이벤트가 없으면 웨이스톤은 발전과제나 아이템 목표로 바꾸고 펫 동행 확인은 선택으로 둔다. |
| `C3-13`–`C3-15` | 모드 구조물 방문을 수동 확인한다. | 실제 구조물 ID와 태그를 확인한다. 안정된 식별자가 있으면 구조물 과제로 바꾸고, 없으면 감지 가능한 발전과제와 선택 안내로 나눈다. |
| `C3-20`–`C3-22` | 상점 방문·잔액 확인·판매가 수동 확인이다. | 새 상점 UI에서 실제 열기와 판매 성공 이벤트를 제공할 수 있는지 구현 시 검토한다. 잔액 확인은 UI에 전용 동작이 있어야 추적할 수 있다. |
| `P-05`, `P-08` | 음식책 진행도와 다중 블록 설비 배치는 수동 과제다. | SoL Carrot의 안정 이벤트를 확인한다. 음식책은 명예 목표로 명확히 안내하고, 설비 감지는 최종 목표로 유지할 가치가 있을 때만 작은 훅을 검토한다. |

기본 우선순위는 기존 발전과제·통계·바이옴/구조물·아이템 과제를 활용하는 것이다. 의미 있는 플레이 행동을 안정적으로 감지할 수 있을 때만 커스텀 훅을 추가한다.

## 보상 시점 점검 후보

아래는 생성 원본의 보상 배치에서 발견한 검토 후보다. 모든 월드에서 무가치하다고 단정하는 것이 아니라, 해당 시점의 보유량과 조달 경로를 확인해야 한다.

| 구간 | 현재 보상 패턴 | UX 우려 | 후속 검토 |
|---|---|---|---|
| `T0` → `C1` | `T0-13`, `C1-05/06/09/12/13`에서 빈 유리병 총 46개 | `C1-13` 시점에는 증류수 병 10개 보유가 목표이며, 음료 사용·충전에서 용기가 반환되면 빈 병이 남을 수 있다. | 물 채우기·용기 반환 규칙을 고려해 누적 수량을 확인한다. 후반 묶음을 줄이거나 생존 편의 보상으로 일부 교체한다. |
| `C2-05` | 작물 분기에서 씨앗/수확물을 돌려주고, 상위 과제가 양배추·토마토 씨앗을 고정 지급 | 양파와 쌀 분기로 완료해도 양배추·토마토 씨앗을 받으며, 같은 작물 분기에서는 보상이 중복될 수 있다. | 선택형 보상, 중립 재배 꾸러미, 또는 상위 과제의 고정 씨앗 삭제를 검토한다. |
| `C2-12`, `C2-27` | 그릇 보상 후 장 완료에서 그릇 16개와 씨앗 각 16개 | 음식 10종·잔치 블록·여러 작물 이후라 그릇과 씨앗이 이미 남을 수 있다. | 조리법 진입에 필요한 최소량인지 확인하고, 과잉이면 부족 재료나 주방 편의품으로 바꾼다. |
| `C3-16/17` | 상점 안내 전에 전리품 목표로 금괴 3개와 5개 지급 | 골드와 SG 코인이 다른 재화라는 점이 불명확할 수 있다. | 퀘스트와 상점 UI에서 두 재화를 구별하고, 실제 구매가와 지급량을 대조한다. |
| `C3-22` | 첫 판매 과제 보상으로 횃불 8개 | 선택형 상점 안내에 늦게 도달한다면 경제 행동과 무관하고 가치가 낮을 수 있다. | 판매 성공 추적이 가능해지면 소액 코인 또는 경제/탐험 편의 보상으로 검토한다. |
| `C4-24`, `C5` | 후반 장 보상에 다이아몬드와 고급 재료 포함 | 이미 같은 발전 재료를 확보한 뒤라면 지연된 환급처럼 느껴질 수 있다. | 최저 비용 진행 경로와 해금된 제작·구매 단계를 기준으로 확인한다. 중복이면 이동·회복·자동화 편의를 우선 검토한다. |

## 보상 검토 기준

보상 시점은 장의 이름상 티어가 아니라 해당 과제를 정상적으로 가장 빨리 끝낼 수 있는 시점으로 본다. 재료가 앞선 과제에서 필요한지, 제출 시 소비되는지, 당시 제작 비용과 파밍 가능성은 어떤지, 다음 목표를 실제로 앞당기는지 기록한다. 확인 없이 보상 티어를 올리지 않는다.
